# Rechenheld

Next.js app with Supabase backend, deployed on Vercel.

## Essential commands

See `justfile`.

## Deployment

Vercel auto-deployment from GitHub is **not** set up. Run `vercel --prod` manually to deploy.

## CLI tools

- `supabase` — Supabase CLI, available globally
- `vercel` — Vercel CLI, available globally

## Testing

Use Rodney for browser-based testing. Run `uvx rodney --help` to see available commands.
